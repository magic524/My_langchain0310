| **条款原文**                                                               | 修改建议                                                                                                        |
|------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------|

**4、保密期限需设定合理上限，防止无限期保密责任**

| **条款原文**                                                                                            | 修改建议                                                                                                                                                           |
|-----------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 除非双方以书面方式同意解除一方或双方在本协议项下的部分或全部保密义务，否则，接收方应对在该项目中获得的披露方保密信息承担持续的保密义务，直至这些保密信息因非接收方原因被公开为止。           | 除非双方以书面方式同意解除一方或双方在本协议项下的部分或全部保密义务，否则，接收方应对在该项目中获得的披露方保密信息承担持续的保密义务，直至这些保密信息因非接收方原因被公开为止。但无论如何，接收方的保密义务自披露方披露该等信息之日起最长不超过十年。上述期限届满后，本协议约定的保密义务终止，但法律法规另有规定的除外。 |
| **修改理由**                                                                                            |                                                                                                                                                                |
| 原条款未设定保密义务的最长期限，可能导致接收方对长期未公开的信息承担永久保密义务，责任过重且不具商业合理性。设定最长十年期限，合理控制保密义务持续时间，降低长期合规风险，符合商业实践，平衡双方利益。 | 原条款未设定保密义务的最长期限，可能导致接收方对长期未公开的信息承担永久保密义务，责任过重且不具商业合理性。设定最长十年期限，合理控制保密义务持续时间，降低长期合规风险，符合商业实践，平衡双方利益。                                                            |

| **修改理由**                                                                                            |                                                                                                                                                          |
| 原条款赔偿范围过宽且无上限，包含甲方及其客户的损失，且未限定损失的可预见性，可能导致乙方承担过重且不确定的赔偿责任。修改后明确赔偿范围仅限于甲方自身的直接经济损失，并设置赔偿上限，有效控制乙方风险。 | 原条款赔偿范围过宽且无上限，包含甲方及其客户的损失，且未限定损失的可预见性，可能导致乙方承担过重且不确定的赔偿责任。修改后明确赔偿范围仅限于甲方自身的直接经济损失，并设置赔偿上限，有效控制乙方风险。                                                      |
