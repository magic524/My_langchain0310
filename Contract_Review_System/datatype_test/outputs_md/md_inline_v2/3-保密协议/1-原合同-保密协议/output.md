# 保密协议

**本保密协议（“本协议”）由以下双方于 2026年02月 02 日签署：**

**甲方：** **江苏陶浦汽车部件有限公司（以下简称甲方）**（样式/段落5: underline）

**乙方：** **上海XXX公司（以下简称乙方）**（样式/段落7: underline）

**鉴于:**

A	乙方为完成 **XXXXXX** 项目，(以下称“ **该项目** ”)，需要甲方提供一些信息供乙方对 **该项目** 进行开发设计和试制。（样式/段落10: color#0070C0, underline）

B.	甲方要求乙方非经甲方书面同意不得披露信息或未经授权地使用保密信息（定义见下）；

**有鉴于此，双方均希望对本协议所述保密信息予以有效保护，并在充分协商的基础上签订下列条款**

**共同遵守：**

**1.	本协议的目的**

本协议的目的是：设定一些双方同意的条款、条件和原则，以便甲方向乙方提供 保密信息 供乙方研究 **该项目** 。（样式/段落20: underline）

**2.	保密信息内容**

在本协议中， **保密信息** 是指由甲方向乙方以任何形式提供的与 **该项目** 有关的任何信息(含专有信息)和文件，如书面、数据电文、口头交流或讨论。以上述方式提供的 保密信息 应属于甲方的财产，许可使用权(除为本协议之目的外)或有关 保密信息 的其他权利不应视作授予了乙方。（样式/段落23: underline）

**3.   保密义务**

自披露方或其知情人员披露保密信息之日起，接收方应履行以下义务：

3.1	未经甲方事先书面同意，乙方不得直接或间接向第三方披露本协议的存在或 **该项目** 的存在。（样式/段落27: underline）

3.2	乙方承诺不向任何第三方披露 保密信息 ，不将 保密信息 用于除本协议目的之外的其他任何目的，并保证不利用这些保密信息试制、制造和销售相同或类似的零部件。（样式/段落29: underline）

3.3 乙方仅向所需最小限度的乙方职工出示所述技术资料文件，并责成该职工承担本协议项下的保密义务。万一该职工发生了违反本协议规定的行为时，乙方将承担赔偿甲方损失的连带责任。甲方有权立即终止与乙方的一切商务活动。

3.4 乙方严格管理与 **该项目** 相关的保密信息。不向除本协议规定的乙方职工以外的其他任何人出示，并不使其发生灭失、丢失等事故。

3.5 乙方保证严格控制与 **该项目** 产品相关的技术资料文件等的复印、眷录或其它记忆媒体的读入，并保证把因开发设计、试制本协议产品而不得不复印、眷录或用其它记忆媒体读入的任何技术资料文件详细的清单、数量书面通知甲方。

3.6甲方将乙甲方获得的零部件价格资料、零部件结构图纸、技术规格、实验方法等信息当作机密对待，不向除甲方职工以外的其他任何人出示，并不使其发生灭失、丢失等事故。

**4.   保密期限**

除非双方以书面方式同意解除一方或双方在本协议项下的部分或全部保密义务，否则，接收方应对在 **该项目** 中获得的披露方保密信息承担持续的保密义务，直至这些保密信息因非接收方原因被公开为止。

**5.  违约责任**

5.1因乙方违反本协议给甲方造成损失的，应赔偿甲方因此所遭受的直接和间接的经济损失，包括但不限于甲方及甲方的客户投入的人力、物力、财力等。

5．2无论何种原因致使甲、乙双方不能继续执行本协议，乙方保证无条件、无偿把所有从甲方得到的与 **该项目** 相关的一切技术资料文件的原件和一切复印、眷录及其它已读入记忆的媒体等信息资料交还给甲方。甲方将保留对有关本协议所述保密信息因乙方原因外泄而造成甲方损失的索赔权利。

**6.	解决纠纷的方式**

如果双方对本协议的履行发生争议，应该本着诚实信用的原则，协商解决，协商不成，应提交甲方所地的人民法院管辖。
