# Agent Markdown 输入模板（metrics 独立）

将你的模型输出整理为类似结构后，保存为：

- `Contract_Review_System/metrics/inputs/agent/review_report.md`

然后运行评测脚本即可，不需要引用 `v1` 目录。

---

## 示例格式

```md
# 合同审查报告

## 合同：1-品牌球馆冠名合作协议

### 条款 1
- 风险级别：中
- 原文摘录：
  > 统一社会信用代码/身份证号：____
- 问题说明：主体信息缺失会导致合同相对方识别不清，增加履约与争议风险。
- 建议修改：补充统一社会信用代码，并附营业执照信息。

### 条款 2
- 风险级别：高
- 原文摘录：
  > 合作期限届满前30日，双方可协商续约事宜。
- 问题说明：续约条件约定不明确，可能产生优先续约争议。
- 建议修改：明确“同等条件”定义，并约定书面通知流程。
```

---

## 注意事项

- 每条风险尽量包含：`原文摘录`、`问题说明`、`建议修改`。
- 若是多合同报告，建议用“`## 合同：<contract_id>`”分段。
- 若你使用 JSON 输出，也可以改用 `--agent-json` 输入。
