# 切分问题说明

## 1. 问题概述
当前原合同条款切分较粗，而采纳情况说明中的风险标签切分较细，二者粒度不一致。

## 2. 具体表现
- 原合同开头的甲方、乙方、联系方式、鉴于段被合并为同一个条款 `c001`
- 采纳情况说明中，这一段被拆成多条风险意见
- 结果是多条风险点同时映射到同一个原合同条款

## 3. 影响
- 报告可读性下降
- 风险定位不够精确
- 后续泛化到新合同时可能不稳定

## 4. 初步判断
该问题部分来自需求方提供材料的组织方式不统一。
`采纳情况说明` 更像审查意见清单，不适合直接作为原合同切分标准。

## 5. 建议
- 保持原合同切分规则独立
- 对合同头部增加更细粒度的字段级切分
- 不直接按采纳情况说明条目数切原合同
